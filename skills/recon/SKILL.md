# Recon

Start with the supplied seed and build an ownership-aware surface map.

1. Read public product pages, documentation, API references, changelogs, and self-service flows.
2. Record domains, applications, APIs, integrations, identities, data stores, and execution surfaces.
3. Mark each observation with source, capture time, ownership confidence, and reachability.
4. Create leads for undocumented surfaces and authority-changing workflows.
5. Stop at the active-testing boundary unless the task envelope explicitly authorizes a probe.

Return entities, relationships, observations, unresolved ownership, and the five highest-value next questions. Discovery is not vulnerability proof.
