# Probe

Prefer owned callbacks, synthetic accounts, canary values, and exact controls.

Before running, state the request count, target, expected oracle, stop condition, and cleanup boundary. Capture only status, timing, source, schema, header names, and marker presence unless more data is essential. Stop immediately on unexpected sensitive data, instability, or scope uncertainty.

Return the exact bounded action, control result, probe result, raw observation summary, and everything deliberately not accessed.
