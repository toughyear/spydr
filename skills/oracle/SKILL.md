# Oracle

Compare the probe with its negative control. Determine which explanations are consistent with status codes, callbacks, timing, logs, state transitions, source network, and independently observed output.

Classify each claim as observed, inferred, confirmed, contradicted, rejected, or unproven. Explain alternative causes and whether the oracle distinguishes sandbox behavior from worker, control-plane, host, or third-party behavior.

Return the strongest justified claim, its exact limit, and the next test that would most increase or decrease confidence.
